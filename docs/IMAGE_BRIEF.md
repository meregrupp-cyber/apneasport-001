# Pildi- ja meediabrief

MVP kasutab olemasolevat repo märki ning abstraktseid CSS/Canvas veekihte. Sportlaste fotosid ei ole
välja mõeldud. Enne tootmisse viimist on vaja:

| Vara            | Desktop | Mobiil | Nõue                                                          |
| --------------- | ------- | ------ | ------------------------------------------------------------- |
| Hero            | 21:9    | 4:5    | Eesti sport / atmosfäär, pealkirjale negatiivne ruum          |
| Vabasukeldumine | 16:9    | 4:5    | realistlik paarilise- ja ohutuskontekst                       |
| Allveevõitlus   | 16:9    | 4:5    | reguleeritud treening, ilma agressiivse/graafilise kujutiseta |
| Merineitsisport | 16:9    | 4:5    | sportlik, oskuspõhine ja mitteseksualiseeritud                |
| AIDA sektsioon  | 21:9    | 4:5    | abstraktne rahvusvaheline võrgustik; logo ainult loaga        |
| MEREGRUPP       | 16:9    | 4:5    | litsentseeritud klubifoto                                     |

Väljundid: AVIF + WebP, korrektne `width`/`height`, sisuline alt-tekst ja dokumenteeritud autor/
kasutusõigus. Hero LCP-variant peab jääma soovituslikult alla 300 KB.

AI-prototüübi korral märgi fail prototüübiks ja nõua valdkonna eksperdi kontrolli varustuse,
turvameetmete, pooside ja anatoomia osas. AI-vara ei tohi kasutada juhatuse-, uudise- ega
võistlusdokumentatsioonina.
